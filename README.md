# LinkedIn Automator

Autonomous LinkedIn outreach tool that sends personalized connection requests and follow-up messages — no Sales Navigator required. Runs locally on **macOS** or Ubuntu using your existing Chrome session.

---

## What it does

**Autonomous Connection Requests**
- Searches LinkedIn for people at target companies
- Scores prospects by role relevance using AI
- Sends personalized connection notes generated by Ollama (or Gemini)
- Respects daily and weekly send limits to stay under LinkedIn's radar

**Autonomous Follow-up Messaging**
- Detects recently accepted connections on the My Network page
- Skips anyone already messaged — each connection is only ever messaged once
- Generates a warm, personalized first message via Ollama based on name and role
- Logs every message sent to `messages.csv` for deduplication and review

## macOS Setup

### 1. Install dependencies

```bash
cd ~/linkedin-automator
pip3 install -r requirements.txt
playwright install chromium
```

### 2. Set up Ollama (local AI — recommended)

```bash
brew install ollama
ollama pull llama3.1:8b
ollama serve   # keep running in a separate terminal
```

> **No Homebrew?** Install from https://brew.sh or download Ollama directly from https://ollama.com

### 3. Configure

```bash
cp .env.template .env
# Default settings work out of the box on macOS — no edits needed unless using Gemini
```

### 4. Log into LinkedIn in Chrome

The app reuses your existing Chrome session. Make sure you are logged into LinkedIn in Chrome before running.

### 5. Run

```bash
# Terminal 1: keep Ollama running
ollama serve

# Terminal 2: start the app
cd ~/linkedin-automator
uvicorn main:app --host 127.0.0.1 --port 8000
```

Open **http://localhost:8000** in your browser.

## Ubuntu Setup

### 1. Install dependencies

```bash
cd ~/linkedin-automator
pip install -r requirements.txt
playwright install chromium
```

### 2. Set up Ollama

```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama pull llama3.1:8b
ollama serve
```

### 3. Configure & run

```bash
cp .env.template .env
uvicorn main:app --host 127.0.0.1 --port 8000
```

## Connection Note Template Variables

| Variable | Description |
|---|---|
| `{{first_name}}` | Prospect's first name |
| `{{company}}` | Their company name |
| `{{role}}` | Their job title |
| `{{ai_hook}}` | AI-generated personalized sentence |

**Example:**
```
Hi {{first_name}}, {{ai_hook}} Would love to connect and swap ideas. — Your Name
```

> LinkedIn limits connection notes to **300 characters**.

## Configuration (.env)

| Key | Default | Description |
|---|---|---|
| `AI_PROVIDER` | `ollama` | `ollama` or `gemini` |
| `OLLAMA_MODEL` | `llama3.1:8b` | Any installed Ollama model |
| `GEMINI_API_KEY` | — | Required only if using Gemini |
| `GEMINI_MODEL` | `gemini-2.0-flash-exp` | Gemini model name |
| `DAILY_CAP` | `20` | Max connection requests per day |
| `TOTAL_HOURS` | `10` | Spread requests over N hours |
| `FUZZY_MATCH_THRESHOLD` | `80` | Company name match strictness (0–100) |
| `CHROME_PROFILE_PATH` | auto | Leave blank — auto-detected |

## Auto-detected Chrome paths

| OS | Path |
|---|---|
| macOS | `~/Library/Application Support/Google/Chrome` |
| Ubuntu | `~/.config/google-chrome` |

If auto-detection fails, set `CHROME_PROFILE_PATH` manually in `.env`.

## Switching to Gemini

```bash
# In .env:
AI_PROVIDER=gemini
GEMINI_API_KEY=your_key_here
```

## Tips

- Click **Test AI** in the UI before your first run to confirm Ollama is working
- Each connection request and message has a **5-second preview window** — click Stop to cancel before it sends
- Use **Pause** to step away mid-session — the run resumes where it left off
- If LinkedIn shows a CAPTCHA, the tool stops automatically and alerts you
- To manually protect someone from receiving a follow-up, add a row to `messages.csv` with their name
